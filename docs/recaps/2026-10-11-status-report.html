01 What works now

  • The collector finds new filings on the SEBI website, downloads each document, and sends one email for all new filings. done
  • The GMP poller gets the grey market premium for each tracked company, matches it to a company record, and stores the result. done
  • The scoring formula uses the grey market premium to predict the listing gain. The email shows this prediction for each filing, as a range from past results, not a single guess. done
  • The update alert checks the grey market premium after the first email and sends a new email when the premium moves five percentage points or more. The alert stops after the company lists its shares or the bid window closes. done

02 What a review process found

A review process checked the code before each commit and found real defects. The process fixed each defect that it found.

  • One defect was a wrong retry on bad data from the API.
  • One defect gave a wrong result from float math at an exact value.
  • One defect kept a record of an email that failed to send.

03 What remains

  • The project does not use a real API key yet.
  • The project has no test with real data from the API yet.
  • The project has no server for the collector and the poller yet.
  • The project has no plan to retrain the formula again later.
  • The project has no decision about old records in the database.
  • The project has no review of the email volume after real use.

04 Actions for you

  • Send a request for an API key to IPO Guru.
  • Choose a server for the collector and the poller.
