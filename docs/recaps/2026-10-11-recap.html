This document gives a status recap of the ipo-watcher project. Read this document before you decide the next step.

01

Phase 1 — the filing collector

Done

The ipo-watcher project has two phases. Phase 1 is a filing collector for the SEBI public issues list. Phase 2 is a score for the listing gain of a new IPO.

Phase 1 is complete. Phase 1 finds new filings, downloads the PDF, and sends one email alert. Phase 1 is stable. No new work is necessary now.

02

Phase 2 — the listing gain score

Formula coded

Phase 2 is a research task. The task identified the best feature for a listing gain score. The feature is the grey market premium, in percent. The short name of this feature is GMP percent.

The team tested seven fundamental ratios and one subscription ratio. None of these features added value to the score. Only GMP percent gives a result with a p-value below 0.05.

03

The formula

The team set a formula for the score. The formula is a linear equation. The formula uses GMP percent as the only input.

predicted_listing_gain_% = −0.2206 + 1.0428 × GMP_%

The team tested the formula against three years of past IPO data. The data set has 147 IPOs with a known GMP percent. The time-based test is the primary test for this project.

MeasureValue
Time-based R-squared0.650
Mean absolute error12.26 points
IPOs in the test147

This is the best result in the project until now.

04

A known risk: the error range is not symmetric

The mean absolute error of the formula is 12.26 points. This number is not a hard range for a single IPO. The real range of past errors is not symmetric. The range skews to the high side. One past IPO listed 74.6 points above its predicted value.

A worked example. A predicted value of +18.4% has a past-error range from about −4% to +48% (5th to 95th percentile). The band is not centered on the dot — big positive surprises are more frequent than big negative ones.

05

Output format

The design spec sets the correct output format. The output format must show the predicted value. The output format must also show the 5th percentile and the 95th percentile of past errors. The output format must show a disclaimer. The disclaimer identifies GMP data as informal data.

06

Data source

Endpoint confirmed, key pending

The team selected the IPO Guru free API as the data source. The project does not use cloud services. This is a standard for the project.

The team tested the IPO Guru API without a key. The API gave a 401 response. A 401 response means that the API is real. A 401 response also means that the API needs a key. The team does not have a key now. A person must request a key by email, and wait for a reply.
